# Modern Chat

Expo Router + NativeWind v4 + Convex (Auth + realtime).

## Запуск
1. `npm install`
2. `npx convex dev` — логін, створення проєкту, генерація `convex/_generated` і `.env.local` (тримайте термінал відкритим)
3. В іншому терміналі: `npm run setup:auth` — JWT-ключі для Convex Auth
4. `npx expo start -c`
